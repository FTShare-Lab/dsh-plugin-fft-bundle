Architecture + Sequence · Settings extension

设置扩展服务（A2）：架构与五段时序

配套 extension-service-design.md。图 1 是架构与两条缝，图 2-6 分别是注册命名空间、注册卡片、端到端读写、卸载与 HMR、可选装配。

01 · 架构与两条缝

浏览器侧一条槽位、宿主侧一个注册表，两侧之间只有一条 HTTP 通道；珊瑚色是本次新增的两个缝。

02 · S1 注册命名空间

校验在写入之前：命名空间非法或重复时抛错且不产生任何副作用。

03 · S2 注册卡片

槽位声明与卡片注册顺序无关：slots.inject 等的是声明，不是服务。

04 · S3 端到端读写

卡片复用共享路由；kline 自己的代码在模块闭包里读到新值，Python 侧是它自己的第二跳。

05 · S4 卸载与 HMR

插件 fiber 一释放，命名空间、路由与卡片同时消失，其余卡片不受影响。

06 · S5 可选装配

两处可选挂载各自等待服务/声明；settings 缺失时整段不生效，插件其余功能照常。
